# Job Description — IoT Cloud Platform Engineer

```
1KOMMA5° — Building the energy system of the future with Heartbeat AI. Goal: transition 1.5 million households to renewable energies by 2030. Over 3,000 people at 80+ locations worldwide. Connect and manage tens of thousands of distributed energy devices at scale.

Your mission: Own the cloud side of our IoT Platform that ingests, routes, and observes every message flowing between our gateway fleet and cloud services. Work at the intersection of cloud infrastructure, messaging systems, data and IoT engineering.

Responsibilities:
- Take ownership of systems at the intersection of Cloud Services and residential IoT Gateways
- Operate and evolve Kubernetes-based IoT Cloud Platform (deployment, scaling, hardening)
- Develop and run Eclipse Hono stack as messaging backbone between gateways and cloud
- Design, build and operate features around fleet management (lifecycle from production to field)
- Integrate with Mender for OTA rollouts across the fleet
- Contribute to load and resilience tests
- Build and own observability pipelines (metrics, alerts, self-healing)
- Build data pipelines and BI models for fleet insights
- Work with product managers, data engineers, IoT engineers, cloud engineers

Technologies: GCP, GKE, Cloud Run, Terraform/IaC, Eclipse Hono, MQTT, Mender, PostgreSQL, BigQuery, SQLMesh, Looker, Datadog, OpenTelemetry, TypeScript/Nest.js, Java, Go, GitHub Actions

Requirements:
- Bachelor's/Master's in CS or related field
- 5+ years building/operating cloud/distributed backend systems in production
- Strong hands-on Kubernetes (ideally GKE)
- Solid understanding of MQTT and device-to-cloud messaging at scale
- Experience with observability pipelines (logs, metrics, traces)
- Comfortable with data and BI tooling (SQL, data modeling, dashboards)
- CI/CD, IaC, platform engineering experience
- Strong reliability and security mindset
- Clear communication in English (German is a plus)

Bonus: Eclipse Hono exposure, Mender/OTA systems, SQLMesh/Looker, GCP primary cloud

Location: Remote (Germany), offices in Hamburg, Berlin or Munich
Seniority: Associate
```
