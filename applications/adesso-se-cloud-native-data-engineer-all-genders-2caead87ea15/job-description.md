# Job Description — Cloud Native Data Engineer

```
Cloud Native Data Engineer

Data-Pipelines umsetzen: Robuste Data-Pipelines, Data Ingest und Data-Processing auf Open-Source-Komponenten wie Apache Airflow, Kafka, Spark oder Trino.
Analytics-Plattformen entwickeln: Containerbasierte Analytics-Plattformen und CI/CD-Pipelines auf Kubernetes-Basis.
Plattformen bereitstellen & automatisieren: Automatisiertes Deployment mit Helm-Charts und Tools wie ArgoCD.
Plattformen betreiben & absichern: IAM, Monitoring und Logging Integration.

Ausbildung & Erfahrung: Abgeschlossen Studium, praktische Erfahrung mit Spark, Kafka, Airflow o. Ä.
Kubernetes Know-How: Deployment-/Service-Definitionen, Secrets, Helm-Charts.
Kenntnisse in der Softwareentwicklung: Java, Scala oder Python, Build- und CI/CD-Tools.
Cloud- und Infrastrukturkonzepte: IaaS, PaaS, SaaS, IaC (Terraform, Ansible).
Sprachkenntnisse: Sehr gute Deutsch- und gute Englischkenntnisse.

Nuremberg, Bavaria, Germany
```
