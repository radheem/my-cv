# Job Description — Python Developer

```
Python Entwickler - ALTEN Germany, Jena. End-to-end development of a communication simulator in Python, including architecture design, implementation and automated testing. Development and extension of an existing simulator with ISO/OSI layers 2-7 focusing on application protocols (TCP, UDP, HTTP). Design and implementation of an interactive GUI dashboard (Dash/Plotly or PyQt/PySide) for real-time visualization and analysis of communication flows. Complex data visualizations and analysis functions for protocol logs, performance and error patterns. Structured developer-centric documentation of software architecture (UML, API documentation). Agile setup with focus on clean code, testability and maintainability. Requirements: CS degree or equivalent, solid Python experience (preferably tools, simulation or backend), deep knowledge of networking protocols OSI Layer 2-7 (TCP/IP, UDP, socket-based communication), GUI application development experience (Dash/Plotly, PyQt, PySide) with data visualization, experience in simulation/analysis tools or developer tools, proficiency with Git and modern CI/CD pipelines and automated testing, excellent English.
```
