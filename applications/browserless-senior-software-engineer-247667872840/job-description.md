# Job Description — Platform Engineer (Mid–Senior)

```
Platform Engineer (Mid–Senior) looking for someone to join a small team that ships fast. The role covers customer-facing APIs, integrations with dependent services, internal tooling, and the security/infrastructure layers underneath — a hands-on role with a wide surface area.

What You’ll Work On:
- Provisioning and managing customer-facing infrastructure across multiple cloud providers
- Extending Terraform setup for new regions
- Building and maintaining integrations with third-party services
- Designing APIs for customer and internal experiences
- Security work: auth, secret management, dependency hygiene, responding to findings
- Reliability work: keeping the platform calm under load, improving observability

Required:
- 5+ years of backend or platform engineering (infra/platform team experience preferred)
- Solid hands-on Terraform and at least one major cloud (AWS, DigitalOcean)
- Strong TypeScript and Node.js — can read/write non-trivial backend services comfortably
- Comfort with Postgres and Redis (cache + coordination primitive)
- Practical security instincts (auth flows, injection/SSRF/IDOR review, secrets handling)
- Experience with billing systems or money-handling code
- Familiarity with AI workflows (LLM integration, agentic features)
- Experience with Playwright or Puppeteer (browser automation)
- Bias toward shipping — scope down, get thin slice into prod, iterate

Nice to Have:
- OpenTelemetry, structured logging, tracing in distributed systems
- Nginx or OpenResty, or other proxy-layer work
- GraphQL schema design
- Next.js / React (when features reach into frontend)
- Small team or early-stage startup background

Tech Stack:
- Languages: TypeScript, Lua, Bash
- Backend: Node.js, Express, GraphQL, PostgreSQL, Supabase, Redis, SQS, S3
- Frontend: Next.js, React
- Infra: AWS, DigitalOcean, Terraform, Docker

Work Style:
- Fully remote — work from anywhere, globally distributed
- Async-first — written communication and deep work optimized, rare meetings
- Core overlap hours: 8am–11am PST, Mon–Thu
```
