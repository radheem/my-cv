# Job Description — DevOps / Cloud Infrastructure Engineer

```
BWI GmbH — Digital future-readiness of the Bundeswehr (German Armed Forces).

TASKS:
- Build, develop and operate highly automated Kubernetes-based infrastructures
- Deployment processes management
- Ensure compliance with security standards (e.g. BSI Grundschutz) and best practices
- Collaborate in agile DevOps team to shape innovative, scalable Private Cloud solutions

PROFILE:
- Completed IT-related degree or comparable qualification with approx. 4 years professional experience
- Knowledge of: Kubernetes (preferably on premise), Linux systems, network fundamentals
- CI/CD pipelines for automation of infrastructure and applications in cloud environments
- GitOps and Infrastructure-as-Code approaches
- Scalability of distributed systems (high availability, redundancy, failover, load balancing)
- Cloud-native tool sets for code versioning

WE OFFER:
- Market-competitive compensation, secure job, employer-funded retirement provision
- 30 days annual leave, 1 traditional holiday + individual adjustments
- Monthly benefit credit via benefit app, tax advantages for ÖPNV tickets
- Flexibility: mobile work, trust-based working time, value account for sabbatical
- Jobrad leasing (up to 2 bicycles)

Location: Nuremberg, Bavaria, Germany
```
