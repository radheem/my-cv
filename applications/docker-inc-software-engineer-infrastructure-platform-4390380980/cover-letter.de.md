## 1. Warum Docker?

Ich vertraue auf Tools, die es mir ermöglichen, mich auf die Implementierung der Logik zu konzentrieren, anstatt mich mit Environment Drift auseinandersetzen zu müssen. Der Fokus von Docker auf die Absicherung von AI agent workflows stellt für mich die nächste wesentliche Ebene des Entwicklervertrauens dar. Mit meiner Bewerbung auf die Position als Software Engineer, Infrastructure Platform möchte ich die Self-Service-Grundlagen mitaufbauen, die diese zuverlässigen, sandboxed Umgebungen für jeden Entwickler zugänglich machen.

## 2. Warum ich?

Auf einer großskaligen IRS-Plattform habe ich Go-Mikroservices entwickelt, die das Messaging von einem Dapr sidecar auf natives NATS JetStream migriert haben. Dies hat die Deployment-Topologie vereinfacht und uns direkte Kontrolle über den Session-State und die Durability gegeben. Ich habe diese Plattform um Model Context Protocol-Integrationen erweitert, die deklarative Tools für LLM agents bereitstellen. Dadurch wurde sichergestellt, dass die Agents innerhalb strikter guardrails operieren konnten, während die vollständige Auditierbarkeit gewahrt blieb. Zu meinen Infrastrukturprojekten gehört das Deployment von Kubernetes-Clustern mit Cilium für sicheres Traffic-Routing, bei dem ich consistent-hashing gateways implementiert habe, um eine vorhersehbare Lastverteilung über mehrere vendor integrations hinweg zu gewährleisten. Zudem habe ich eine resiliente document ingestion pipeline mit Hatchet entwickelt, die deklarative retries und timeouts durchsetzt und so die Datenqualität auch bei worker crashes während der Verarbeitung garantiert.

## 3. Warum jetzt?

Mein Hintergrund in Go-basierter platform engineering, Kubernetes operations und AI-assisted automation entspricht der technischen Tiefe und dem Self-Service-Mindset, das Docker schätzt. Ich stehe ab sofort vollzeitlich zur Verfügung und befinde mich in Deutschland, mit der Flexibilität, mich innerhalb von zwei Wochen umzuziehen. Da ich im Besitz einer Blue Card bin, kann diese ohne zusätzlichen sponsorship overhead direkt in einen qualifizierenden Arbeitsvertrag überführt werden. Dies gewährleistet einen reibungslosen und unmittelbaren Start, um Ihre Infrastrukturziele zu unterstützen.
