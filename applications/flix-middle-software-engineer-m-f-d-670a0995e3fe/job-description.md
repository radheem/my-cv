# Job Description — Backend Engineer

```
Join Geo Information Systems team – Supply Division. Build and operate an end-to-end platform that ingests, processes, and visualizes real-time vehicle and ride data.

Backend has been rewritten in Scala 3 around Kafka Streams.

Responsibilities:
- Build backend services and streaming applications that power real time insights for millions of passengers
- Strengthen automated testing, expand end-to-end test coverage, improve delivery pipeline reliability
- Take ownership of services throughout lifecycle (design, implementation, deployment, monitoring, improvement)
- Work with cross-functional team to solve complex technical challenges
- Help shape engineering culture through collaboration and knowledge sharing

Requirements:
- At least 4 years experience in software development
- Experience with a JVM-based language (Scala)
- Experience building web applications (HTTP APIs)
- Infrastructure and CI/CD experience (Terraform, GitLab CI)
- Ownership mindset, data analysis and modelling skills
- Strong communication and documentation skills

Nice-to-have: Kafka streaming apps, Kubernetes, spatial/geolocation data, AWS, ML exposure

Benefits: Travel perks, work from anywhere 60 days/year, hybrid work, wellbeing support, L&D, mentoring
```
