# Job Description — Backend/DevOps Engineer

```
Develop, operate, and continuously improve stable, scalable, and secure backend services following the "You build it, you run it" principle
Ensure high code quality, maintainability, and technical excellence through refactoring, reviews, and engineering best practices
Evolve backend architectures with a focus on performance, reliability, scalability, and cost efficiency
Build and maintain CI/CD, deployment, and automation pipelines, as well as comprehensive testing strategies
Leverage Generative AI and AI-assisted engineering tools for development, documentation, testing, and optimization
Enhance observability through logging, monitoring, and tracing while ensuring the availability and resilience of production systems

Requirements: Degree in CS or equivalent, strong programming skills in PHP, Node.js, or Go. Experience with AWS, Kubernetes, CI/CD, automated testing, SQL, NoSQL, caching. Hands-on experience with AI-augmented engineering. Good German & English.

Benefits: 30 days vacation, remote work in Germany and worldwide, sabbatical, meal allowance, EGYM Wellpass, JobRad, company pension plan.
```
