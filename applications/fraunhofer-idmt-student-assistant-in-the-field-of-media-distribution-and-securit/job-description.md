# Job Description — Research/Software Engineer (Implied)

Tasks vary depending on current projects. You will support:
- Development of AI software projects
- Signal analysis, data protection
- Creation of web demonstrators

Required tools and programming languages: Python, Tensorflow, Javascript, Git, Docker
