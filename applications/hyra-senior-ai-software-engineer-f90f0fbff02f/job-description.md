# Job Description — Senior Full-Stack Engineer

```
A leading global provider of healthcare software solutions is looking for an experienced engineer to join the team in Berlin. Focus on developing advanced web applications and integrating intelligent features across a diverse SaaS portfolio to improve healthcare outcomes.

What you'll be doing:
Develop and operate modern web applications across a comprehensive SaaS portfolio.
Integrate native intelligent features and agentic experiences using large language models.
Design and maintain cloud-native services with a focus on reliability and security.
Collaborate with product and architecture teams.
Translate complex healthcare workflows into functional software features.

Requirements: Senior-level experience in full-stack engineering with React, Angular, Java, or Python. Advanced degree (Master's or PhD) in CS. Experience with Kubernetes, Terraform, and Kafka. Full professional proficiency in both German and English.
```
