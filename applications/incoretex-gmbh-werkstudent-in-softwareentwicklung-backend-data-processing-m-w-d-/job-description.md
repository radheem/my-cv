# Job Description — Student Software Developer Backend & Data Processing

```
Werkstudent/in Softwareentwicklung Backend & Data Processing (m/w/d)

Incoretex ist ein schnell wachsendes High-Tech Unternehmen an der Schnittstelle von IoT, Sensortechnologie und KI. Die Technologie von Incoretex erleichtert die Integration von KI in bestehende Produkte und senkt deutlich die Zeit und Kosten, die mit der traditionellen Produktentwicklung verbunden sind. Gemeinsam mit renommierten Partnern aus verschiedenen Industrien schaffen wir somit anspruchsvolle High-Tech-IoT-Anwendungen für spannende, weltweite Märkte.

Aufgaben:
- Entwicklung von Prozessen zur Datenverarbeitung und Analyse
- Code reviews
- Bugs Fixing
- Entwicklung von leistungsfähigen Algorithmen zur Bewegungsanalyse
- Erarbeitung von Konzepten für das Verwalten und Auswerten großer Datenmengen
- Enge Zusammenarbeit mit anderen erfahrenen Entwicklern und Partnerunternehmen

Qualifikation:
- Du befindest dich im Studium der Informatik oder vergleichbarer Studiengänge
- Du kannst im Team und eigenverantwortlich arbeiten
- Du besitzt Erfahrungen mit objektorientiertem Programmieren, Process Handling, Parallel Programming, Datenstrukturen und Code Reviews
- Du bist vertraut mit C++ (17 oder höher), Python 3, (Postgre)SQL und Bash/ZShell
- Du willst dich persönlich weiterentwickeln und dich aktiv in einem jungen, dynamischen Umfeld einbringen

Von Vorteil sind Kenntnisse mit CMake, Doxygen, Docker/Podman, nftables, MQTT, Protobuf und Libraries.

Standort: Aachen, North Rhine-Westphalia, Germany
```
