# Job Description — Software Developer

```
Software Developer (m/w/d) – Standort Aachen (Hybrid)

Ihre Aufgaben:
- Eigenverantwortliche Umsetzung: Konzeption, Entwicklung und Wartung von anspruchsvollen Softwareanwendungen und -lösungen.
- Qualitätssicherung: Sauberer, performanter Code für neue Features, komplexe Bugs beheben, Unit- und Integrationstests.
- Wissenstransfer: Unterstützung Junior-Entwickler bei fachlicher Entwicklung, Code-Reviews.
- Schnittstellenarbeit: Zusammenarbeit mit funktionsübergreifenden Teams (Produktmanagement, Qualitätssicherung, DevOps).
- Dokumentation: Technische Spezifikationen und Systemdokumentationen.
- Agiles Arbeiten: SCRUM-Meetings und kontinuierliche Prozessverbesserung.

Das bringen Sie mit:
- Mehrjährige, fundierte Berufserfahrung in professioneller Softwareentwicklung, komplexe Projekte.
- Tech-Stack: Sehr gute Beherrschung moderner Programmiersprachen und Frameworks (vorzugsweise C#, .NET / ASP.NET Core).
- Architektur & Daten: Solid understanding of software architecture, relational databases (SQL / PostgreSQL), modern cloud architectures.
- DevOps & Tooling: Fundierte Kenntnisse mit Docker, Kubernetes und Helm sowie CI/CD-Prinzipien.
- Cloud-Mindset: Cloud Native Mentalität (Erfahrung mit Azure Cloud ist ein großes Plus).
- Soft Skills: Problemlösung, strukturierte und selbstständige Arbeitsweise, Teamfähigkeit.
- Sprachkenntnisse: Exzellente Englisch-Kommunikationsfähigkeiten.

Wir bieten:
- Internationales, dynamisches Arbeitsumfeld
- Spannende und innovative Projekte mit globaler Reichweite
- Moderne Technologien und Möglichkeit, technische Entscheidungen aktiv mitzugestalten
- Kurze Entscheidungswege, flache Hierarchien
- Individuelle Weiterbildungs- und Entwicklungsmöglichkeiten
- Flexible Arbeitszeiten sowie hybrides Arbeitsmodell
- Attraktive und leistungsgerechte Vergütung
```
