# Job Description — Data Engineer

```
Kreditz is transforming how businesses assess credit and risk using real-time data and NextGen Credit Scoring solutions. As one of Europe's fastest-growing FinTech scaleups. Data is the core of our product. We turn raw bank transactions into real-time insight that powers credit & risk decisions across Europe.

Responsibilities: Maintain & Enhance the DWH - Own the architecture of our Data Warehouse. Pipeline Automation - Design, build, and maintain robust ETL/ELT pipelines. Stakeholder Enablement - Work with Product, Finance, and Commercial teams. AWS Infrastructure - Leverage AWS services (Glue, Redshift, Athena, Lambda, S3). Data Quality & Governance - Implement monitoring and validation frameworks. Collaborate with DevOps and Backend teams.

Requirements: BSc/MSc in quantitative subject. 3+ years experience in Data Engineering. Expert-level SQL skills. Proficiency in Python. Strong hands-on experience with AWS (Redshift/Snowflake, S3, Glue, Lambda). Solid understanding of data warehousing concepts (Star Schema, Kimball). Experience with orchestration tools (Airflow, Dagster) and CI/CD (GitHub Actions). Ability to translate technical data structures into clear insights.

Meritorious: Terraform. FinTech/Open Banking experience. BI tools (QuickSight, PowerBI).
```
