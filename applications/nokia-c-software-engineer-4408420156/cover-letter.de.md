Infrastruktur zu bauen, die für Nutzer unsichtbar bleibt und im Hintergrund massive Skalierung bewältigt, ist der Bereich der Softwareentwicklung, der mir am meisten Spaß macht. Die Mission von Nokia, optisches Networking mit KI-gesteuerten Entwicklungstools zu vereinen, deckt sich exakt mit diesem Fokus. Ich bewerbe mich für die Position als C++ Software Engineer, um an diesem Rückgrat mitzuwirken. Mein Hintergrund im Aufbau verteilter, ereignisgesteuerter Plattformen hat mir gezeigt, wie Systeme so konzipiert werden, dass sie auch unter Druck stabil bleiben und sich gleichzeitig leicht weiterentwickeln lassen. Ich bringe eine nachweisliche Erfolgsbilanz beim Ausliefern produktionsreifer Dienste, beim Automatisieren von Quality Gates und bei der Zusammenarbeit in verteilten Teams mit, um komplexe Architekturen in zuverlässige Software zu verwandeln.

Auf einer Plattform im Stealth-Modus zur Steuerungsverarbeitung ersetzte ich eine aufwendige Sidecar-Abhängigkeit durch ein natives Messaging-System namens NATS JetStream sowie eine direkte Service-zu-Service-Kommunikation. Diese Änderung reduzierte die Komplexität der Bereitstellung und sorgte für vorhersagbare Latenzzeiten über mehrere Vendor-Integrationen hinweg. Ich verknüpfte diese architektonische Änderung mit automatisierten End-to-End-Datenqualitäts-Gates und einer strengen Schemavalidierung, die Diskrepanzen abfing, bevor sie die Produktionsumgebung erreichten. Darüber hinaus integrierte ich einen Model Context Protocol Server, der externen KI-Agenten die Interaktion mit der Plattform über eine deklarative Konfiguration ermöglichte und damit den von Nokia für seine Engineering-Teams aufgebauten, KI-unterstützten Entwicklungsworkflow widerspiegelte. Diese Erfahrungen haben meine Fähigkeit geschärft, sauberen, entkoppelten Code zu schreiben, strenge Code Reviews zu leiten und Software auszuliefern, die hohen Zuverlässigkeitsstandards entspricht.
