# Job Description — QA Engineer / Software Tester

```
Tasks:
Creation and maintenance of test plans and test cases based on requirements and specifications
Conducting manual and automated tests using various tools such as Selenium, LoadRunner, or HP ALM
Development and maintenance of automated test scripts using tools such as TestNG, Selenium, Java, C# or Python
Analysis of test results and documentation of errors in the bug tracking system
Collaboration with developers to reproduce and fix bugs
Participation in the further development of the SDLC and in the introduction of agile methods such as Scrum or Kanban
Ensuring compliance with quality standards through regular reviews and tests in various environments
Support in integrating tests into continuous integration processes

Qualifications:
Solid knowledge of software testing as well as experience with test automation tools such as Selenium or LoadRunner
Experience in using version control systems such as SVN or TFS, as well as in using Jenkins for continuous integration
Knowledge of programming languages such as Java, C#, Python, C++ or PHP, as well as databases and SQL
Familiarity with web technologies such as HTML, CSS, JavaScript, JSP, and frameworks such as Node.js or.NET is desirable
Experience working with agile methods such as Scrum or Kanban
Good analytical skills and a structured working method
Teamwork skills and communication strength
```
