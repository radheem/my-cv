# Job Description — Data Infrastructure Engineer

```
Design, build, and maintain the data infrastructure that powers Business Intelligence and AI initiatives. Transform fragmented data sources into reliable, scalable, and actionable data assets.

Responsibilities:
- Data Pipeline Development: Design, build, and maintain robust ETL/ELT pipelines
- Business Alignment & Impact: Partner with cross-functional teams, translate business challenges into scalable technical data solutions
- Data Architecture & Warehousing: Develop and maintain data models, warehouses, and storage solutions
- Data Integration: Consolidate data from diverse sources (Jira, Confluence, source code repos, CRM systems)
- AI/ML Readiness: Prepare structured and curated datasets to support analytics, ML, and AI initiatives
- Data Quality & Governance: Implement data quality controls, monitoring, validation, and lineage tracking
- Database Optimization: Design and optimize database structures, queries, and storage solutions
- CI/CD: Contribute to CI/CD practices, automated testing, deployment pipelines

Must-Have:
- BSc or MSc in Computer Science, Data Science, Analytics, or equivalent
- Strong proficiency in Python for data processing, automation, and API integrations
- Strong SQL skills and experience with relational databases (PostgreSQL, MySQL, Oracle)
- Experience designing, building, and maintaining ETL/ELT pipelines
- Experience with source control and CI/CD using GitLab
- Excellent communication skills in English

Nice to have: Airflow, dbt, Power BI/Tableau, AI/ML experience, Docker
```
