# Job Description — Full-Stack Integration Engineer — Industrial Automation & AI Middleware

```
Title: Full-Stack Integration Engineer — Industrial Automation & AI Middleware
Location: Remote / Hybrid
Tech Stack: Python, Node.js / TypeScript, REST APIs, Webhooks, Docker, SQL/NoSQL
About the Role
We are hiring a Full-Stack Integration Engineer specializing in custom automation bridges, middleware applications, and digital interfaces for manufacturing environments. You will build software solutions that replace physical shop floor paper (travel sheets, manual inspection plans, physical clock-ins) with real-time digital interfaces, automated document extraction pipelines, and backend integrations.
Key Responsibilities
Develop microservices and API connectors linking shop-floor hardware (MES terminals, scanners) with enterprise backends.
Build clean, intuitive worker interfaces to eliminate printed work instructions and manual paper logs.
Implement lightweight AI/OCR modules for automated document processing and delivery receipt extraction.
Participate in rapid, agile sprint cycles focusing on iterative value delivery.
Requirements & Qualifications
3+ years of software engineering experience with strong focus on API integration and middleware development.
Proficiency in backend development (Python, Node.js/TypeScript) and relational databases.
Experience interfacing with shop-floor terminals, scanner devices, or enterprise REST/GraphQL APIs.
Interest or experience in leveraging AI APIs/LLMs/OCR for document automation.
Fluent in English.
```
