# Job Description — Data Engineer

```
We're looking for a Data Engineer to join our Data Infrastructure team and help build the shared data platform that powers analytics and AI across Schibsted Media. You'll work with technologies such as Snowflake, dbt, Airflow, and Python.

What You'll Do: Collaborate with Data & AI teams to understand platform needs. Design, build, and improve shared data platform capabilities, developer tooling, data pipelines, and automation using Snowflake, dbt, Airflow, and Python. Support and evolve Privacy Compliance Platform. Deploy, maintain, and improve cloud infrastructure using IaC. Improve reliability, observability, performance, cost-efficiency, and scalability. Develop reusable templates, tooling, and documentation. Develop maintainable data models. Contribute to good practices for data modeling, transformation, testing, documentation, and governance. Participate in code reviews.

Requirements: 4+ years experience as Data Engineer. Strong SQL skills. Experience building data pipelines with Airflow or similar. Hands-on experience with dbt. Experience with Python. Experience with Git. Good communication skills. Collaborative mindset.

Nice to have: Experience with automated testing, CI/CD, code review. Experience with Snowflake. Experience with Terraform. Experience with AWS, GCP, or Azure.
```
