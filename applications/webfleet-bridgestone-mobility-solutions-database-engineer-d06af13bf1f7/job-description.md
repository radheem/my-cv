# Job Description — Database Engineer

```
Database Engineer - Leipzig, Germany (Bridgestone Mobility Solutions / Webfleet) - Job ID 2026_15560

Are you an exceptional Database Engineer with deep PostgreSQL expertise and solid Oracle knowledge? Do you thrive on solving complex reliability and scalability challenges, driving automation, and shaping modern database platforms? We're looking for engineers with a strong ownership mindset who challenge the status quo, collaborate across disciplines, and are passionate about building resilient, secure, and high-performing data services in a truly agile environment.

At Webfleet, you'll have the opportunity to influence our database platform, elevate engineering practices, and help define the future of our mission-critical infrastructure.

What You'll Do:
- Design, improve, and maintain reliable, scalable, secure, and high-performing database platforms and services,
- Operate, maintain, and optimize PostgreSQL databases in production environments,
- Work with PostgreSQL in Kubernetes-based environments, including CloudNativePG / CNPG Operator,
- Support and maintain Oracle database environments,
- Analyze and optimize SQL queries, indexes, execution plans, schemas, and database performance,
- Improve database availability, backup and restore, replication, high availability, and disaster recovery processes,
- Monitor database health, capacity, performance, logs, metrics, and alerts,
- Troubleshoot incidents, performance issues, data issues, and operational problems,
- Improve database security, access management, data integrity, and compliance-related processes,
- Support database upgrades, patching, maintenance, and lifecycle management,
- Help improve database change management, release readiness, and operational processes,
- Automate recurring database administration and operational tasks where useful,
- Collaborate with development teams, architects, product owners, DevOps engineers, and system engineers to support reliable delivery of new features,
- Contribute to database reviews, operational reviews, infrastructure reviews, and technical discussions.

Who are you? Requirements:
- Solid experience as a Database Administrator, Database Engineer, Database Reliability Engineer, or similar role,
- Strong hands-on experience with PostgreSQL administration and production operations,
- Knowledge of PostgreSQL in Kubernetes-based environments, ideally with CloudNativePG / CNPG Operator,
- Good knowledge of Oracle database administration and operations,
- Strong experience with SQL, query tuning, execution plan analysis, indexing strategies, and performance troubleshooting,
- Experience with backup and restore, replication, high availability, disaster recovery, and database monitoring,
- Good understanding of database architecture, storage, capacity planning, data integrity, and database security,
- Experience with database upgrades, patching, maintenance, and operational lifecycle management,
- Familiarity with automation or scripting for recurring database administration tasks,
- Interest in working closely with software engineers, architects, component owners, DevOps engineers, and system engineers,
- Strong communication skills, an analytical mindset, and a goal-oriented, quality-focused approach,
- A willingness to learn and adopt new database technologies and operational practices as needed by the team,
- Fluency in English.

Nice to have:
- Knowledge of AWS or cloud-based database operations,
- Experience with database observability tools such as Grafana, logs, metrics, and alerting,
- Experience with infrastructure as code or automation tools,
- Familiarity with Kubernetes or containerized environments from a database operations perspective.

Benefits: 30 annual leave days, flexible hybrid work model, home office setup payment, work abroad 40 days/year, birthday off and volunteering time off, LinkedIn Learning, Gofluent languages, CALM app, Employee Assistance Program, childcare support, 100% employer funded pension, Bridgestone tyre discount.
```
