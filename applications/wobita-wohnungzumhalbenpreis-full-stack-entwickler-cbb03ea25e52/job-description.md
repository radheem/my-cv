# Job Description — Full-Stack Developer

```
Wir suchen einen Full-Stack-Entwickler zur Verstärkung unseres Teams für die Weiterentwicklung unserer modernen Immobilienplattform Wobita. Du arbeitest an Backend, Frontend und Infrastruktur gleichermaßen und setzt dabei auf einen modernen, KI-gestützten Entwicklungsworkflow.

Was wir bieten: Flexible Gleitzeit, Homeoffice, Moderner Tech-Stack & KI-gestützter Workflow, Flache Hierarchien, Mitgestaltung, Weiterbildung.

Deine Hauptaufgaben: End-to-End Feature-Entwicklung über den gesamten Stack (Backend, Frontend, Deployment); Backend mit NestJS & TypeScript; Frontend mit Next.js (App Router), React & TailwindCSS; Design & Implementierung von APIs (REST, optional GraphQL); Datenbankdesign, -modellierung und -optimierung (PostgreSQL, ORM); Aufbau & Pflege von CI/CD-Pipelines und Deployment-Infrastruktur; Code-Reviews, Qualitätssicherung und technische Dokumentation; Effizienter Einsatz KI-gestützter Tools (z. B. Claude Code) im täglichen Workflow.

Tech-Stack: Sprachen: TypeScript/JavaScript, SQL, Python. Backend: NestJS, Node.js, REST-API-Design, PostgreSQL, ORM (Prisma/Drizzle/TypeORM), Auth (JWT, CSRF). Frontend: Next.js (App Router, Server Components), React, TailwindCSS, State (Context, TanStack Query), Figma. KI-gestützte Entwicklung: Claude Code, Prompt-Engineering, MCP-Anbindung. DevOps: Git, Docker, CI/CD (GitHub Actions), Monitoring/Logging.

Qualifikationen: Berufserfahrung in der Web-Entwicklung von Vorteil, nachweisbare Code-Erfahrung mit NestJS und Next.js, SOLID-Prinzipien, Deutsch fließend. Nice-to-have: Web/SaaS-Plattformen, API-/Backend-Architektur, PropTech-Domäne, Monorepo (pnpm, Turborepo, Nx), GraphQL, Testing (Jest, Vitest, Playwright).
```
