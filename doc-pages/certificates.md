## Detailed Curriculum

### Deep Learning Specialization — DeepLearning.AI
*Issued via Coursera · January 2020*

A comprehensive 5-course specialization designed and taught by **Andrew Ng**, focusing on the foundations and practical implementation of modern deep learning models.

1.  :material-file-pdf: **[Course 1: Neural Networks and Deep Learning (PDF)](./certificates/deeplearningai_cert/Coursera_dls_course1.pdf)**
    *   *Syllabus:* Vectorization, Python deep learning foundations, activation functions, forward/backward propagation, L-layer neural network construction.
2.  :material-file-pdf: **[Course 2: Improving Deep Neural Networks (PDF)](./certificates/deeplearningai_cert/Coursera_dls_course2.pdf)**
    *   *Syllabus:* Hyperparameter tuning, L2/Dropout regularization, Batch Normalization, Optimization algorithms (RMSprop, Adam), Xavier/He weight initialization.
3.  :material-file-pdf: **[Course 3: Structuring Machine Learning Projects (PDF)](./certificates/deeplearningai_cert/Coursera_dls_course3.pdf)**
    *   *Syllabus:* ML strategy, human-level performance (HLP) analysis, training/dev/test set mismatch resolution, orthogonalization, multi-task learning.
4.  :material-file-pdf: **[Course 4: Convolutional Neural Networks (PDF)](./certificates/deeplearningai_cert/Coursera_dls_course4.pdf)**
    *   *Syllabus:* CNN architectures (YOLO, ResNet, Inception), padding/pooling, object detection, bounding box regression, face verification, neural style transfer.
5.  :material-file-pdf: **[Course 5: Sequence Models (PDF)](./certificates/deeplearningai_cert/Coursera_dls_course5.pdf)**
    *   *Syllabus:* Recurrent Neural Networks (RNNs, GRUs, LSTMs), natural language processing, word embeddings (Word2Vec, GloVe), Beam Search, Attention Mechanism, Transformer models (self-attention, multi-head attention).
