# Job Description — Platform Engineer

```
Northwind Cloud — Platform Engineer (Remote, EU)

We run a multi-tenant developer platform on Kubernetes and are looking for a
platform engineer to own our cluster tooling and developer experience.

You will:
- Operate and harden our Kubernetes clusters (networking, ingress, DNS).
- Build GitOps-style delivery with kustomize/Helm and CI/CD.
- Improve observability (metrics, tracing) and reliability.
- Work with Go and Python services and their gRPC APIs.

Must have:
- Strong Kubernetes experience (CNI, ingress, LoadBalancer).
- Go or Python, container tooling (Docker), and CI/CD.
- Comfort with cloud-native networking and DNS.

Nice to have:
- Cilium / eBPF, Terraform, observability stacks (Prometheus/Grafana).
- Experience running developer platforms.
```
