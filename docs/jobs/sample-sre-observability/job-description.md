# Job Description — Site Reliability Engineer

```
Harborview Systems — Site Reliability Engineer (Remote, EU)

We operate a high-traffic SaaS platform on Kubernetes and are hiring an SRE to
own reliability, observability, and incident response.

You will:
- Define and track SLOs; lead blameless incident reviews.
- Operate and harden Kubernetes clusters (networking, ingress, autoscaling).
- Build and own the observability stack (metrics, logs, tracing).
- Improve rollout safety and reduce deployment toil with CI/CD.

Must have:
- Strong Kubernetes experience and Linux fundamentals.
- Go or Python, container tooling (Docker), and CI/CD.
- Hands-on with Prometheus/Grafana and distributed tracing.

Nice to have:
- Cilium / eBPF, Terraform, on-call leadership.
- Experience running high-availability, multi-tenant platforms.
```
