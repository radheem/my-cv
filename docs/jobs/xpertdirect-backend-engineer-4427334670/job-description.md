# Job Description — Backend Engineer

```
Backend Engineer (Node.js)

Remote (Company based in Berlin, Germany)

6-Month Initial Contract + Potential Extensions

E-commerce Technology | Digital Commerce Platforms

For one of our clients, a rapidly growing e-commerce technology scale-up based in Berlin, we are looking for a Backend Engineer to help build and scale the services that support a high-volume digital commerce platform serving customers across Europe.

This role is ideal for engineers who enjoy solving performance, scalability, and integration challenges while working on products used by thousands of customers every day.

Technical Environment

• Node.js

• TypeScript

• PostgreSQL

• REST APIs

• Cloud Services (AWS preferred)

What You'll Be Working On

• Designing and developing backend services and APIs

• Building scalable systems supporting high transaction volumes

• Developing integrations with payment, logistics, and third-party commerce platforms

• Optimising application performance and database efficiency

• Supporting platform scalability, reliability, and security initiatives

• Collaborating closely with product, frontend, and platform engineering teams

Experience Required

• 4+ years of backend software development experience

• Strong Node.js and TypeScript expertise

• Experience designing and building production APIs

• Experience working with relational databases such as PostgreSQL

• Strong understanding of scalable application architectures and distributed systems

Nice to Have

• E-commerce platform experience

• Event-driven architectures

• Docker and Kubernetes

• Microservices environments

• Experience with payment systems or marketplace platforms

Why You Will Love This Role

✔ Fully remote engagement

✔ Modern technology stack

✔ High-impact product development work

✔ Fast-moving scale-up environment

✔ Opportunity to contribute from day one

✔ Strong likelihood of extension as the platform continues to scale
```
